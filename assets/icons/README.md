# Toolbar icons

These PNGs were rendered. They were not drawn by hand in this repo.

The typeface is JetBrains Mono, under the SIL Open Font License. The font was used only to render these PNGs. The font files are not in this folder and are not part of the extension.

The PNG files must not be edited by hand, re-encoded, or regenerated.

The colored ON glyph is `icon-16.png`, `icon-32.png`, `icon-48.png`, and `icon-128.png`. The gray OFF glyph is `icon-16-off.png`, `icon-32-off.png`, `icon-48-off.png`, and `icon-128-off.png`. `master-512.png` is the 512 master and is not a manifest icon.

`scripts/gen-icons.mjs` writes solid squares at different filenames and is not the source of these files.
